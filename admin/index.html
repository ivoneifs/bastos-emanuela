Falta ligar o banco

O painel está pronto. Só faltam duas informações do Supabase.

  1. Crie um projeto no Supabase (plano Free serve).
  2. No SQL Editor, rode o arquivo supabase/schema.sql deste repositório.
  3. Em Project Settings → API, copie a Project URL e a chave anon public.
  4. Cole as duas no começo deste arquivo, em CONFIG, e publique de novo.

A chave anon é feita para ficar visível no site — quem protege o banco são as regras de acesso criadas pelo schema. Nunca use a chave service_role aqui.
